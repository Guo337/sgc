# 社区记忆项目对照与吸收边界

> 结论（**2026-09-27 原判断，2026-11-22 已修正，见下方更正节**）：社区有相近方向，但**无一成熟项目完整覆盖 TTL 生态位**（Obsidian 原生运行时 + ROOT/Atlas/Card 渐进路由 + L1/L2/L3 分层 + fast-iterate/careful 姿态 + Git 治理 + 反馈驱动规格演化 + harness 引脚/vault 权威分离）。TTL 宜定位为 **Obsidian 原生 Agent 知识治理协议与参考实现**，非普通 memory backend。
>
> 证据来源：工作区 `community-research/`（5 项目浅克隆快照 + 外部综述，**仅本地只读参考、不入库、不执行其代码**）。本卡只结晶"借什么/不借什么"的判断，不复制任何后端。

## 2026-11-22 采样偏差更正（独立比对推翻原前提）

**原结论「无一成熟项目完整覆盖」已被源码级独立比对推翻大半。** 2026-09-27 调研采样 6 项目（Loreweave/FIL/KnowledgeGuard/SwarmVault/mnem/Local REST API），漏掉了当时生态里最强的三个同类项目：

- **basic-memory**（立项时已存在 22 个月，Markdown 权威+混合检索含 CJK+doctor 全成型，AGPL）
- **gbrain**（立项时已迭代至 v0.58，检索/dream/PreCompact banking/BrainBench CI 全在；trust tiers 10-08 诞生晚于本项目 init，MIT）
- **dory**（wake→提案→人审→canonical 全管线立项时已完整，MIT，已归档）

**归因**：漏掉 basic-memory/gbrain 是检索方法缺陷（词族窄+未查 MCP 目录/OpenClaw 生态），非信息不可达；dory 低显著性为辅因。详见 `Audit/Current/FOUNDING-STATE-RESEARCH-2026-11-22.md`（时间线证据）与 `Audit/Current/COMMUNITY-COMPARISON-INDEPENDENT-2026-11-22.md`（八维比对）。

**修正后定位**：本项目真实独特性收窄为协议/方法论/实验记录（治理即文本一等公民、KNOWN-LEAKY 诚实缺口台账、脚本卷形态、文档↔实现对账、确定性投影 diff=∅、联邦复制身份、盲态收敛实验），**非运行时能力**。分层生命周期、人审提案、append-only 审计、盲测评在 dory/gbrain 均有更强代码实现。公开叙事已改为「治理即文本参考实验+诚实过程实证」，显式承认 gbrain/dory 为更强运行时（见根 README）。

**原卡下方内容保留作历史判断记录**（2026-09-27 时点认知），吸收原则中「不引第二知识权威」仍成立，但「保持现架构」的论证前提（无完整覆盖）已不成立——是否融合、融合多深待 Owner 裁（四路径见独立比对报告 §10）。

## 五项目生态位（一句话）

| 项目 | 存储权威 | 核心强项 | 对 TTL |
|---|---|---|---|
| **Loreweave** | 用户 Markdown（SQLite 仅可重建缓存） | BM25/图扩散/PPR、bitemporal 事实、supersede、dream 报告 | 最接近检索实现 |
| **FIL-Coding-Agent** | Git 中 Markdown | 治理分层(CLAUDE/AGENTS/DECISIONS/DYNAMIC/LOG_ERRORS)、错误预防 | 最接近治理思想 |
| **KnowledgeGuard** | `knowledge/*.md` | JIT、渐进披露、facts-driven、局部 patch | 最接近读取纪律 |
| **SwarmVault** | raw/wiki/state + 图产物 | doctor、candidate/审批队列、graph diff、context pack、多层 smoke | 最接近产品化工具链 |
| **mnem** | 自有内容寻址库 | Git 式版本/branch/tombstone、混合 GraphRAG、token accounting | 最接近版本化底座 |

## 吸收原则（借语义 / 借测试 / 借方法，不引第二权威）

保持现有架构，**不复制任何社区项目的完整后端**；社区机制只作"可替换思想"吸收，Obsidian CLI 仍是唯一主运行时、Markdown/frontmatter 仍是唯一权威状态（对齐 [[SPEC-READ]]、[[SPEC-GOVERN]] 与命门 [[PIT-嵌套wikilink识别]]）。

## 可靠性分级（外部综述的判断，本卡沿用并复核）

- **A 级（可直接作架构输入）**：Loreweave 确定性索引/可重建缓存/时间事实/失败记录；FIL 治理层级/ADR/错误预防；KnowledgeGuard JIT/渐进披露/facts-driven；SwarmVault 测试分层/doctor/context pack/变更诊断；mnem 版本/撤销/token 透明。
- **B 级（须在 TTL 重新验证，不因论文/README 宣称就采纳）**：PPR 边扩散收益；embedding 是否改善中文/多域；时间衰减/FSRS 是否优于简单 recency；自动冲突检测准确率；自动反思结晶会否造重复/错误卡；Agent hook 是否真降低漏读 ROOT。
- **C 级（不应直接继承）**：“自动学习”即等于可靠；公开 benchmark 能证明长期治理质量；同一 Agent 产出+审核+合并算独立审查；大 graph/db 可替代 Obsidian 人类可读运行时；功能数量=成熟度。

## 当下采纳 vs 不引入

**已/将采纳（因地制宜）**：
- doctor 结构化报告 + **每条 issue 带修复方向** + 重复/冲突/陈旧/孤岛检查（借 SwarmVault doctor + Loreweave dream）——已落 entry_doctor v2。
- **golden-set + A/B 评测纪律**，指标不只看 Recall（过期误召回率/错误升级率/provenance 覆盖/回滚成功率/token 与延迟/解释完整度）——解答独立裁判(F 点)。
- supersede/tombstone **取代而非物理删除**（借 mnem/Loreweave）——复用现有 `rel: supersedes`，当前检索默认排除被取代项。
- “把**失败**写进 changelog，不只晒成功 benchmark”（Loreweave 纪律）——并入日志/PIT 文化。

**明确不引入**：独立向量库/云端 memory service；viewer/多格式 ingest/桌面应用；FSRS 衰减（对我们未证收益）；把所有卡改造成 bitemporal（仅对有时间变化的 L2 claim 试验 `valid_from/valid_until`）；默认 LLM 抽取事实；无角色隔离的多 Agent 自动互审；第二套图链接引擎。

## 对 TTL 路线的影响

外部综述的 P0–P4 与第二份评审的 Stage 0–4 高度一致，已归并进设计文档"统一实施路线"。P0（把已有协议接成闸门：doctor `--use-cli` 真交叉核对、HEAD/索引一致性、Atlas/ROOT 可达性硬检查、`--json` 稳定 schema、pre-merge 命令）即本轮 entry_doctor v2 的落点。当前 TTL 定位：**架构接近 Reference prototype，执行器尚未达其全部最低能力，整体 pre-alpha**。

## 存疑

- 五项目均为 2026-09-27 浅克隆快照，非实时；其"已实现"结论以快照 commit 为准，引用需注明版本。
- 外部综述本身是 AI 协助产物，本卡按三层分诊（真 bug/暂态/哲学分歧）复核其判断，未盲信；A/B/C 分级中 B 级项在 TTL 落地前都须自证。
