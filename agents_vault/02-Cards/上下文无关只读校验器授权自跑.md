# 上下文无关只读校验器授权自跑

## 定义

当某工具大半职能与对话上下文无关（输入=工作树、输出=确定报告），可授权 Agent 在迭代期自跑、无需逐次请示，作为提交前自检闸门。

## 核心

reflect 编译自候选结晶（来源：log-2026-09-28-02，用户 2026-09-28 特批）：

**授权判据**（四条同时满足）：

1. 纯标准库/无外部副作用依赖；
2. 只读——不改盘、不写库；
3. 结果确定——同输入同输出、可复现；
4. 失败安全——自身异常不破坏数据（退出码区分）。

满足则 Agent 可自跑（如 entry_doctor 离线闸门），与 SPEC-GOVERN §提交节奏"提交前必跑 doctor"一致。**边界**：一旦工具带写入/不可逆副作用（如 reflect.py --apply），不在此授权内，仍需显式确认或走治理流程。

## 存疑

- "上下文无关"是程度判断而非布尔：doctor 的 --use-cli 依赖 App 内存索引状态，严格说非纯上下文无关，故其一致性靠规约+软提示兜底（见 SPEC-GOVERN §分支切换）。

## 应用

本库迭代期用户已特批 Agent 自跑 doctor 闸门；判据可复用于决定"哪些校验工具可免请示自跑"。
