# 表述精确性纪律

## 定义

Agent 产出文本时的三条言语行为纪律，针对**表述-理解偏移**（漂移1：单次表达-解码误差，白噪声型）：断言先核实物、转述不升格、指称给锚点。本卡是该类漂移的**唯一宿主**——后续同型实例累积挂靠于此，不另立卡。

## 核心

### 三条初版（corr-62 双例 + Owner 2026-11-16 裁决）

据以结晶的前篇原文（[[corr-2026-11-16-62]] 教训列，引文纪律首演练）：

> 对「东西存在哪」的事实断言必须先定位实物；「我改不了」是最容易免检的断言——它免除了自己的行动义务，恰好因此最该被核验

> 设计文档里的「永久/必须/需要」在兑现时应重新对磁盘核验，规划期的判断不豁免执行期的证伪

1. **能力/位置断言先定位实物**：说「X 存在哪」「我改不了 X」之前，先机械定位 X 的存储介质（文件/配置/数据库记录）。「我改不了」是最容易免检的断言——它免除自己的行动义务，恰好因此最该被核验。
2. **转述不得升格情态**：复述前文时保持原认知强度——「保留」不得变「永久保留」，「建议」不得变「必须」，「权宜」不得变「设计终态」。升格=给文本断言注入未经核验的权威。
3. **指称用可解析锚点**：引用库内对象用路径/wikilink/corr id，不用「那个文件」「之前的方案」类模糊指称；听者（含未来的自己）须能一跳到达实物。

### 迭代机制（Owner 裁：规范自身须可迭代）

- **触发**：出现**新偏移形态**（不是同形态重例）才议修订；同形态重例只追加实例节。
- **上限**：条文 ≤7 条；到顶时先合并抽象再增补，防条文通胀。
- **策略定位**：漂移1 是白噪声，**不追求彻底消除**——降频 + 等 LLM 进步（Owner 2026-11-16 裁）。本卡是「加正则」不是「造闸门」；无机械执行者（E 原理：执行者=Agent 自觉，显式接受风险）。
- 与漂移2（系统偏差累积）的分工：累积型由 [[03-CHANGE-DISCIPLINE]] 引文纪律 + [[04-REPORTING]] 认知标签治（事中/事前）；本卡治单次型（事后累积降频）。引文纪律把漂移2 降维成漂移1 后，残余归本卡。

## 存疑

- seed 单源：仅 corr-62 双例 + 本会话调研，跨会话/跨 Agent 复用未检验。
- 三条初版是否完备未知；第三例新形态出现前不扩条文（三连用纪律）。
- 「情态升格」的边界（同义改写 vs 升格）无机械判据，靠实例校准。
