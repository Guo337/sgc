# Beta 闸门判据（FROZEN，公开件）

> **本件是判据的公开载体，不是宣告。** 项目当前仍为 **Alpha**。Beta 宣告须 B1–B6 逐项达标留痕 + Owner 显式 go/no-go；FAIL 无 experimental 出口。
> 判据经 Owner 2026-11-24 裁决冻结（r4 + r4-b），本件为冻结文本的库内公开版；裁决过程与证据吸收见库内更正链（corr-107/109/112/113/115/117/119/120）。

## 0. Beta 定义（每一处 Beta 标签旁必须带此句）

> **Beta = 治理协议可移交**：一个不了解本项目开发史的外部项目 Agent，仅凭公开库内文本（引导卡+规格+工具卷），能独立建起副库、运转写入循环；建库与写入循环全程无主库维护者排障介入（任何主库侧提示都记为协议缺陷→修公开文本→重测）；上提按协议角色运转（产出者≠验收者≠Owner 终审），Owner 裁决属协议内角色、不算「介入」。担保协议的可采用性，不担保每条结论正确，不承诺检索/产品级能力。

与 Alpha 的关系：Alpha 担保「过程确定/诚实/可复现/可审计」；Beta 把 Alpha 显式登记的边界（治理文本尚不独立约束 Agent）变成下一个可证伪命题——撤走维护者，只留公开文本，外部 Agent 能否被这套文本治理着建库+运转+上提。

**不解除 scope freeze**：Beta 规划不授权新阶段能力（STATUS §5 约束沿袭；CI 豁免为唯一显式修订，逐字登记）。

## 1. B1–B6 冻结判据

| # | 验收项 | 冻结判据 |
|---|---|---|
| B1 | 冷启动可建库 | ≥1 份**合格外部样本**：真实外部 Agent（异机、无本项目会话历史、不喂结论/任务书），只给公开 repo URL，按 README→AGENTS→引导卡自建副库：doctor 0E + 探针 HIT + 库外问题诚实 GAP；中间态 BROKEN_LINK 按引导预期出现并归零。任何主库侧提示=协议缺陷→修公开文本→重测。本机子 Agent 预演只算预演不算达标样本。多样化样本（非 Windows/非 Copilot/非中文母语）列 Beta 后推广波，不入达标线 |
| B2 | 写入循环自治 | 副库内真实会话 ≥5（=服务其项目本体任务的会话，非库维护微任务），跨 ≥2 个不同任务日；L1 身份行/四段模板合规；自然错误走 correction（不造任务）。逸出计量：协议内机制捕获=可接受 KNOWN-LEAKY；靠 Owner 察觉=协议外介入。不要求零逸出，要求逸出被协议内捕获并如实计量披露 |
| B3 | 联邦回路双向 + re-sync + 修订权契约 | 上提验收六步再走 ≥1 次真实上提（不合格被正确拒绝与合格被并入同等计证据）；**re-sync 补建后验**：基于 diff 的规格升级协议设计+实现（卷化）+主库↔副库真实走通 ≥1 次，保 provenance:copied 身份与本地更正链。**修订权契约扩展**：①规格修订权契约入权威层——本地可改+机读声明偏离：copied 规格允许副库本地修订但须可校验声明，治理红线分区不可改，规格级修正可走上提通道回流，冲突各库 Owner 裁本库、跨库归主库 Owner 终审；②上行回流通道：副库规格级修订可被发现与验收（上提对象从普适卡扩至规格修正）；③端到端样本**须含本地偏离**（副库本地修订→上游升级→按契约处置→双方修订链完整可溯），纯原样升级不算覆盖 |
| B4 | 公开门面自足 + CI 矩阵 | **CI 矩阵绿**：GitHub Actions 跑 vol_extract→doctor→self-test × ubuntu/macos/windows 三平台全绿；+人工双态首验留痕（Win/POSIX × 抽取 sha/doctor/self-test/探针逐格证据指针）；README 自举配方 PowerShell+bash 两版按文面可走通；仓根完整性白名单对账（.gitattributes/LICENSE/.gitignore/README/AGENTS/GLOSSARY、零历史 init、隐私扫描零残留） |
| B5 | 关键缺口台账诚实 | KNOWN-LEAKY 台账覆盖全部已知无执行者不变量；检索=0、多副库并发未实测等短板公开显式可见；recency GHOST 就地标记；单写者边界 README 醒目；门面口径终检一遍一致 |
| B6 | Owner go/no-go | B1–B5 逐项核验留痕（L1+证据指针）→ Owner 显式宣告；FAIL 无 experimental 出口。反馈闭环前置：试建/评审暴露的缺口须修进公开文本并**取得重测确认留痕**（issue 评论/回证）才算闭合——维护者单方宣称修复不算 |

**不在门槛内**（显式排除，防 scope 膨胀）：检索能力、压缩恢复产品化、多副库并发实测。

**Beta 后候选批（登记不实施）**：L1 完整性 manifest、同步脚本卷化、多样化冷启动推广、脱敏复现 kit、doctor「薄」可计算判据、候选结晶批。
