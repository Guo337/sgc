## 为什么改（原来错在哪）

- **D33 协议裂缝（独立架构评审实证）**：D33 原条款假设随时在线的 Owner；非交互子 Agent 三通道全不可用时合规路径不存在（只读审计被卡死）。测试 Agent 活体实例：MCP failure→REST 拒连→CLI 需 App→未自启→磁盘读（未批准，如实留痕）。与「智能体无关化/可平移」宣称张力。Reader 权限补此裂缝，不放松写入侧。
- **密钥纪律默认自己人视角**：速查卡写给本库维护者 Agent（默认有权读插件配置），外来审核者无合规取 key 指引——测试 Agent REST 401 后裁量不碰凭证降 CLI，裁量合理但文本缺口真实。
- **W4 治理根本法自称草案**：外部读者困惑源，Owner 终审认可现行文本升 v1.0.0。
- **gitignore 逐文件枚举漂移**：新卷落地未同步排除清单，反物化数字层纪律的又一实例（枚举=第二份维护责任）。
- **门面宣称超出实物**：「轻代码」易误读为代码少（实际 7505 行≈治理文本 1.53 倍，轻在权威形态不在体量）；「可 re-sync」超出身份机制卡存疑节；「永不空手」纯脚本路径不成立。
