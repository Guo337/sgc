# corr-116：快照同步脱链误伤卷封修复

## 改了什么

- Audit/Current/sync_public_snapshot.py `delink_audit` 跳过 `script-volumes/` 目录：卷是字节封工具面（sha256 对围栏代码块），脱链正则把卷内 self-test 夹具字符串里的 markdown 链接（如 ``p``）改成纯文本，破坏字节封→vol_extract 拒抽（sha256 mismatch）。
- 修复后重跑同步：10 卷全抽、doctor 双模式 0E/0W/0I（280 md）、隐私扫描零残留；公开快照 Guo337/sgc 推 ceb22d6→d78adda（doctor v2.17.0+rest_read v0.2.1+schema v0.7.6+corr-106~115）。

## 为什么改（原来错在哪）

波①给 entry_doctor self-test 加了 06-Project 夹具，夹具字符串含 markdown 链接；同步工具的 PROJECT_LINK 脱链正则无差别扫所有 .md 含卷正文，把代码字面量当知识散文脱链。卷正文是工具面不是知识 prose，其链接是代码字面量，不应脱链。此 bug 在波①前不显形（旧卷夹具无此类链接），属波①引入的耦合缺陷。

## 依据

- 实测：快照 entry_doctor 卷 parse FAIL sha256 mismatch（declared bcb417e1… actual e48f981f…）；diff 私库/快照卷仅 3 处夹具链接被脱链；跳过后 parse OK、全链验证通过。
- 卷字节完整性纪律（c-ansys-00004 候选卡同族）：卷正文原样复制，仅 frontmatter 可插标记。
