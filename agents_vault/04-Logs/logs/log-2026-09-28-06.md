3. **REST 只读连通验证成功**：`GET document-map status=200 version=1d0e11`、认证通过、守卫 no-op 端到端正确（工具 shell 与用户终端 env 隔离，故走 --key-from-plugin 读 data.json）。

- **写入闭环达成（朋友报告 P2）**：append_log.py 把 append-only 守卫落成可执行原语，中断/重复/漂移/block-style 均 fail-loud 不静默损坏；offline 为唯一落盘通道（逐字节精确、self-test 8 PASS）。

## 存疑与风险

- **REST 写路径 --apply 未实测**：POST new-log / PATCH backfill 的 --apply 已禁用（frontmatter 重排坑）。若未来要安全用 REST 写，需改走 PUT 整文件（自算 byte-exact 内容 + If-Match），待验 PUT 是否支持 If-Match + 原始内容（批次5 候选）。
- **block-style 仅 fail-loud、未支持读写**：离线解析器遇 block 风格 frontmatter 只拒绝不解析；若用户常在 Obsidian UI 编辑日志 frontmatter（会被重排为 block），需增强 parse_inline_list/fm_get 真正兼容 block（批次5 候选）。

- **cli 通道仅 dry-run**：官方 obsidian append 的 --apply 未接线（多行内容经 CLI 单参数易碎）。
