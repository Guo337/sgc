## 结论与产出

**touched 是 Spec 语义要求（但语义边界不精确）；正文 wikilink 是实现层利用的隐式边；orphan 出边不可逆**：

- **A. touched**：[[SPEC-WRITE]] 记入协议明列 touched 为 L1 frontmatter **必填**（id/project/session-task/touched/created）；[[T-log]] 注释语义="本次会话动过的文件"（用链接表达）；`schema.yaml` 定义 `touched: list[link]`（无 minItems）。故 touched 是 **Agent 声明的语义关联** + 用 link 结构化表达 -> 客观产生图边（一体两面）。但 `schema.yaml` constraints 的"至少一条边/孤岛"是 **L2 卡**约束、**L1 不判 orphan/stale**，故 touched:[] 技术合法（doctor PASS）。
- **B. 正文 wikilink**：[[SPEC-READ]] 图检索前向多跳取 **e/k/v 里的链接**（L2 卡边字段），**未把 L1 正文 wikilink 明定为 memory relation**；但 [[PIT-嵌套wikilink识别]] 确证 Obsidian 链接引擎扫全文双链（含正文）进反链/图谱/search，`read_orchestrator.py` one-hop 亦当 mentions 边。故正文 wikilink 是 **Obsidian 原生能力 + 检索实现利用的隐式边**，非 TTL Spec 对 L1 的显式要求。
- **C. 库内惯例**：Grep 全库 23 条 L1，**22 条 touched 非空**（含只读引用的文件，如 [[log-2026-09-28-01]] touched 含读过的 SPEC-GOVERN），**唯 [[log-2026-10-07-01]] touched:[]**（上一轮把"动过"窄解为"仅修改"、只读观测遂填空）-> 空 touched 非惯例、系个例失误。
- **可达性实测（MCP vault_read native）**：[[log-2026-10-07-01]] links=[]（出边空）、backlinks=[log-02]（log-02 落盘后补的 1 入边）；[[log-2026-10-07-02]] links=7 条、backlinks=[]。**验证上一轮 log-02 声称的"给 log-01 增入边"成立**；但 log-01 出边因 append-only 永不可追补 -> **orphan 事后修复单向、被动、依赖外部引用**。

## 存疑与风险

- **F-SEM-1（语义模糊，规范层）**：[[T-log]] touched 注释"动过的文件"字面偏"修改/操作"，但库内 22 条惯例含"读取/引用"的文件（宽义"涉及"）。语义边界未在 Spec 精确界定 -> Agent 易窄解（如上一轮 log-01 只读遂填 []）。这是 touched 语义**记入规范不够精确**，非纯脚本问题。
- **F-SEM-2（FRICTION）**：orphan L1（links=[]）出边不可逆（append-only），事后只能靠新 log 反向引用补入边，无法从根上修复其正向可遍历性。
- **U1（UNKNOWN）**：touched:[] 是否应被 doctor 判为 L1 结构缺陷？现状 `schema.yaml` 明确 L1 不判 orphan（与 L2 区分），但 22/23 惯例暗示 touched 非空是隐性规范。**Spec 未明定 L1 最小关系数**，证据不足以断定"空 touched=违规"。
- **U2（INSUFFICIENT EVIDENCE）**：仅抽查 3 条 L1 + Grep touched 字段；正文 wikilink 与 touched 的"关系表达充分性"未系统量化（多少 L1 正文零 wikilink 仅靠 touched？未全库统计）。不据 3 例下全局结论。
- **拒绝错误合并（anti-convergence）**：不将"touched = semantic correspondence"划等号——touched 是"涉及文件"的操作关联，semantic correspondence（如 derives_from / contrasts_with）是 L2 卡 e.rel 的语义关系，两者层次不同，不并入。
- **处置**：F-SEM-1/2、U1/U2 均触及 Spec / 记入规范语义，按"先报告不自动开发"记 candidate，NOT OWNER DECISION。
