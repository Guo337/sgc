## 结论与产出

- **最终锁定架构**：读取→插件 MCP 主通道（明文 27123，低摩擦原生工具治"误以为"）；写入→官方 CLI（D23，byte-exact，第一方）；插件不碰写入；CLI 读命令/grep/Python 降为兜底。SPEC-READ v0.6 已消 v0.5"读取主走 CLI、MCP 可选增强"漂移。
- **Qoder IDE vs CLI 的 MCP 工具过滤差异（铁证）**：includeTools/excludeTools/permissions.deny/alwaysAllow/trust 是 CLI settings.json→mcpServers 专属；IDE effective config 丢弃 includeTools、无配置级工具白名单，仅服务器级 disabled/autoApprove + 逐次确认。故 6 只读白名单在 IDE 只能靠 agent 自律（方案C），固化于 mcp.json description + SPEC-READ A.6 + 记忆三载体。
