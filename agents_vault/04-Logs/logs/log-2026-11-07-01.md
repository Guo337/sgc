## 做了什么

- 迁移矩阵实测（更深路径、段内含空格、三种 cwd × 脚本位置 × `--vault` 全组合）：读工具一直从 `__file__` 派生根，从不读 cwd。**路径无关性此前已成立**，原假设不成立。
- 由此转向真正的缺陷：`entry_doctor --use-cli` 调 `obsidian unresolved` 时不 pin vault，且完全忽略 `--vault`，等于把被扫库与「Obsidian 当前焦点库」强行对账。
- 实测本机归属：`obsidian.json` 中有两个同名 `vault`（`<other-vault>` 与 `<workspace>/vault`，本机绝对路径已匿名化）。无参 `obsidian files` 列出 `00-moc/`、`30-long-term/`，不属本库；`obsidian vault=vault file path=00-ROOT.md` 报 not found，而 `00-ROOT.md` 正是本库根卡。结论：CLI 一直在答另一库。
- 修复两层：先用 `vault=<名>` 定向；再用离线刚扫到的真实相对路径（最浅优先，`00-ROOT.md` 打头）做存在性复核，**通过才采信**；不通过则降级离线并报出原因。
- 根解析统一为 `--vault` → `$TTL_VAULT` → 脚本 `../..`，缺失时报出路径与决策来源；`read_orchestrator` 补上此前未支持的 `$TTL_VAULT`。
- 补齐 3A 字节锁：3A manifests v1–v4.3 哈希锁定 16 个文件（10 篇 md + 6 个 reducer），此前未标 `-text`，在 `autocrlf=false` 克隆上全部失配。加锁前先验证当前工作区 53 条目全部吻合，确认属**预防性修复**，而非修复已损坏的封存件。
- `SPEC-READ` v0.6.4 写入两条约束：CLI 通道须先证明 vault 归属；根解析次序与来源报告。

## 结论与产出

- 「路径无关化」的正确结论是：**不需要改路径解析，需要补通道身份证明**。二者都表现为「换机器就不对」，但根因不同。
- 修复前的所有 `--use-cli` 对账结论是针对错误 vault 得出的，**一律作废**，不得再作为分歧证据引用。
- 修复后，一个 Obsidian 从未打开、故意含 1 条断链的临时 vault 不再产出伪造 `CLI_RECONCILE`，而是正确降级并说明「未以该 vault 打开」。
- 8 个 manifest 共 53 条目，在 `core.autocrlf=true` 与 `false` 的全新克隆下均全部通过（修复前 `false` 下 3A 为 0/5）。
- 离线对账当前实现口径：65 文件，links 0 / backlinks 0 / unresolved 0。候选取证变体的分歧不在本结论范围。

## 存疑与风险

- 两个同名 `vault` 未改名，CLI 歧义仍在；现有身份复核是**防御**，不是消因。
- `unresolved` 是插件命令而非内置命令。插件缺失时 CLI 通道会整体降级，这并不等于「离线与 Obsidian 一致」。
- 「同名 vault 导致错库」是本机观测，换机须重测，不可外推为 Obsidian 通用行为。
- 迁移矩阵的 cross-vault 比较排除了 `.md` 计数（克隆缺未跟踪卡），该差异尚未独立解释。
- 3A 历史 manifests v1–v4.3 并列存在且状态各异（`frozen` / `frozen_for_retry`），未标注 superseded 关系；当前有效件为 v4.3，但这一点只靠上下文表达，未在文件内声明。
- 3B 的 `certification: UN-CERTIFIABLE` 与 `final_projection_match: 6/7` 未因本次改动发生任何变化；本次提交只涉及字节存储方式。

## 候选结晶

> 以下均为 candidate，不自动升格为 L2/L3 稳定知识。

1. **通道归属须用「只有该库才有的对象」证明**：名称参数、版本回复、退出码都能在「别的库」上同样成立；只有解析一个本库独有的相对路径才算证明。
2. **空结果必须与失败响应可区分**：`No unresolved links found.` 与 `Command "unresolved" not found.` 在只看退出码时同义，会把「通道失效」静默读成「零分歧」，而且这个错误方向恰好是自证清白。
3. **「本机可验」不等于「可移植」**：哈希锁定的封存件必须显式禁止行尾转换；否则另一平台克隆后 hash 必失效，而本机永远看不到这个失败。
