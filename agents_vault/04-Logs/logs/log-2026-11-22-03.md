# log-2026-11-22-03：独立审计轮 + 公开叙事改口

## 做了什么

1. **派三个独立子 Agent**（均只读、不喂我方结论、唯一写入物=各自报告）：
   - 公开就绪审计：全库+快照逐项扫（隐私全量 grep+长随机串甄别、逐文件 hash diff、断链、内容适宜性通读、卷自举可达）→ **可公开，零 BLOCKER，6 WARN，8 INFO**。
   - 社区独立比对：本项目 vs basic-memory/dory/gbrain 源码级八维比对+融合追加章 → 独特性收窄为 7 件协议/方法论/实验记录（非运行时能力）；gbrain 治理+认知诚实两维整体更强；融合四路径（丁1 loreweave 侧车 3~4 刀亲和性最高）；inline-list 约定建议放弃（推翻既有裁决，列选项）。
   - 立项时点考证：GitHub API 锚定 2026-09-26 三竞品真实状态（basic-memory 22 个月/gbrain v0.58/dory 全管线已成型）；漏检归因=检索方法缺陷（词族窄+渠道单一）非信息不可达；反事实 fork dory 可省 6 卷大部+提前 7 周；哲学件 11-12 后才形成不构成当时必须自研理由。
2. **门面 README 重写**（corr-100）：5 行→~80 行自足门面（命名展开+TTL 双关 Time to Live/Through the Lens+改名原因+诚实定位+检索不足自述+快速开始+指针节）；W1 死链修。
3. **叙事改口**：对照卡加采样偏差更正节（原「无完整覆盖」前提被推翻，定位收窄）；Atlas README 映射注记补 TTL 双关。
4. **W2/W3/W5/W6 修**：D35 改名状态回写、inbox 卡号改磁盘实测为准、GHOST 移除 atlas_fill、决策索引库外路径同步 Audit/History 迁移。W4（SPEC-GOVERN 草案标签）留 Owner 裁。

## 结论与产出

- 公开就绪：快照可公开（零 BLOCKER），门面自足、叙事诚实、隐私干净、结构自举完备。公开动作（init+建仓+push）仍留 Owner 终裁。
- 项目定位诚实化：从「社区无完整覆盖」改为「治理即文本参考实验+不洗白过程实证」，显式承认 gbrain/dory 更强运行时。独特性 7 件全是协议/方法论/实验记录，非运行时能力。
- 融合路线待裁：丁1 loreweave 侧车（MIT/零网络/CJK+PPR 现成/3~4 刀）性价比最高；inline-list 放弃与否是推翻既有裁决的大事；单写者原则是任何融合的根本约束。
- TTL 双关来历落盘（Owner 告知）：Time to Live + Through the Lens，立项恶趣味，非缩写，与现理念关联已淡，历史保留不改写。

## 存疑与风险

- **inline-list 放弃建议**（比对报告 §10.5）：与三家主流序列化对抗的孤例，PIT 整族坑源于此，改 block 零语义损失——但推翻既有 Owner 裁决（PIT-frontmatter重排 系列），只列选项不擅动。
- **W4 SPEC-GOVERN 草案标签**：规格实际已运行多轮，摘标签还是保留草案态须 Owner 裁（规格情态变更）。
- **融合第三方依赖**：丁1 引 Node 依赖+第三方信任面（须按红线 A.5 人工审源）；丙 BM 侧车有 AGPL 灰区+只读性未实证疑点。是否融合、融合多深是 Owner 在「实验控制权 vs 轮子税」间的裁量。
- **考证不确定项**（报告 §8）：各项目 9-26 当天 star 数无历史 API（量级为标注推断）；dory 真实起点经 scrub 不可考；gbrain 9-26 本地化后端程度未核；旧调研实际搜索词/渠道未记录（方法缺陷归因从采样构成反推，标注推断）。
- **公开叙事改口的边界**：门面/对照卡/Atlas 已改，但库内其他文件（Specs/日志）中残留的「无完整覆盖」类历史表述属 L1 append-only 不改——公开快照含这些历史文件，读者可能看到旧主张与新门面并存；这是 append-only 设计的正常形态（历史判断+更正注记并存），不构成矛盾，但门面已显式说明定位修正。

## 候选结晶

- 「立项史作为第一份被治理的知识」模式：认知诚实项目的门面应包含对自身起源错误的诚实叙述（漏检归因+代价+残值），而非仅展示成果——此模式可复用于任何以诚实为卖点的研究项目公开叙事；暂挂本 log，待公开后外部反馈验证再考虑入卡。
- 「独立审计不喂结论」模式：三个子 Agent 均只读+不喂我方结论+唯一写入物=报告，有效避免了锚定偏差（比对报告修正了我先行分析的多处判断：dory 权威方向/独特性范围/最优融合路径）——此模式可复用于任何需要独立验证的内部主张；与 EFG 独立裁判原理同构，暂挂待第二次真实出现。
